1. 기기에서 처리하는 정보
여음은 마이크로 박수와 주변 소리를 녹음해 주파수 대역별 잔향시간을 추정합니다. 녹음에는 주변 대화 등 개인에 관한 내용이 포함될 수 있으므로 공유 전에 확인해주세요. 측정값·원본 녹음·분석 진단·측정 시각·기기 및 오디오 설정을 기기에 저장합니다. 직접 입력한 장소·메모와 선택적으로 촬영한 공간 사진도 저장합니다. 위치 권한을 요청하거나 GPS 위치를 수집하지 않습니다.

2. 외부 전송
이 버전에는 계정·광고·분석 SDK·개발자 서버로의 자동 업로드·앱 자체 클라우드 동기화가 없습니다. 일반 CSV/JSON 내보내기에는 녹음·사진을 첨부하지 않습니다. JSON에는 분석 곡선과 진단 정보가 포함됩니다. 공유 이미지에는 미리보기에 표시된 장소·메모·측정 시각·결과·주의 문구와 선택한 사진이 포함됩니다. 진단 ZIP에는 원본 녹음이 포함되며 별도 선택을 통해 공유합니다. 사용자가 시스템 공유창에서 선택한 앱과 서비스에 전달한 정보는 해당 서비스의 정책에 따라 처리됩니다.

3. 사진과 권한
마이크 권한은 측정 시작 시, 카메라 권한은 사진 촬영 선택 시 요청합니다. 사진 없이도 측정하고 공유할 수 있습니다. 촬영한 사진은 재인코딩하여 앱에 저장하며 원본 촬영 EXIF를 복사하지 않습니다. 사진 보관함 전체 접근 권한은 요청하지 않습니다. 권한은 iPhone 설정에서 변경할 수 있습니다.

4. 보관·백업·삭제
완료 측정의 결과와 사진은 삭제할 때까지 기기에 보관합니다. 원본 녹음과 진단 파일은 검토와 재분석을 위해 보관합니다. 취소·중단된 측정에서도 이미 저장된 원본이 남을 수 있습니다. 앱이 관리하는 기록·사진·Captures 폴더는 OS 백업에서 제외하도록 설정합니다. 앱 삭제 시 로컬 데이터가 사라집니다. 사용자가 Files나 외부 앱으로 복사한 파일은 이 설정의 적용 대상이 아닙니다.
지난 기록에서 기록을 삭제하면 연결된 사진과 원본도 삭제합니다. 데이터 관리에서 선택한 기록의 원본만 삭제하거나, 이전 실험·취소 녹음을 포함한 전체 데이터를 삭제할 수 있습니다. 외부로 공유·내보낸 사본과 이메일은 앱에서 삭제되지 않습니다. 저장소 오류가 생기면 삭제가 일부만 완료될 수 있으며 앱 안내를 확인하고 다시 시도해주세요.

5. 문의와 변경
사용자가 이메일로 보낸 주소·본문·첨부파일은 문의 대응을 위해 메일 서비스에서 처리됩니다. 민감한 녹음·사진을 보내기 전 첨부 내용을 확인해주세요. 문의 내용과 첨부의 삭제 요청은 위 이메일로 보내주세요. 기능이나 처리 방식이 바뀌면 이 문서를 갱신합니다. 공개 배포 전 최종 시행일과 문의 보관 정책을 확정합니다.

이 웹사이트에 관하여

이 사이트는 별도 회원가입·문의 폼·분석 스크립트·광고·외부 폰트 없이 제공하는 정적 페이지입니다. GitHub Pages에 공개하는 경우 호스팅 제공자인 GitHub가 접속 정보 등을 처리할 수 있습니다. 앱 내부 데이터 처리와 별개이며 GitHub 개인정보처리방침을 확인할 수 있습니다. 이메일 링크를 누르면 사용자의 메일 앱이 열립니다.
